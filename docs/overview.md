# kaeno

## Purpose
kaeno is an application that helps endurance athletes plan, manage, and analyse their training.

## Principles
- **Privacy-first**: All user data is stored locally on the device — never on a server.
- **Offline-first**: The application does not require a network connection of any kind.
- **Web-first**: Built entirely on web technologies so it runs on any device.

## Core Use Cases
1. Plan training sessions
2. Create and reuse workout templates
3. Manage training zones per discipline and metric
4. Track performance progression (thresholds, training zones, personal bests)
5. Track health data (weight over time)
6. Plan races (not yet designed)

## Success Criteria
- Onboarding of athletes < 5 minutes
- Intuitive interface

## Key Constraints
- Full functionality without a network connection
- User data must stay local on their device

## Out of Scope (for now)
- Sync data to another device
- Integration to platforms like Strava and TrainingPeaks
